1. 需求背景

业务背景

当前公司合同管理流程在 OA 系统中完成，合同归档后数据仅存储在 OA 内。结算中台在进行内容结算时，需要依赖合同中的关键信息（尤其是单价、分成比例、合作周期等版权信息），目前只能由结算人员手动前往 OA 系统查询合同详情后再回到结算中台操作，流程割裂、效率低下且容易出错。

用户场景

  • 结算人员在中台发起结算时，需要查看对应合同的单价、分成比例等字段，当前只能另开 OA 系统逐一查找
  • 结算主管需要按合同维度汇总结算情况，缺少合同数据在中台的统一视图
  • 合同到期续约时，需要快速查看历史合同条款作为参考

业务价值

  • 打通 OA 与结算中台的合同数据链路，消除信息孤岛
  • 结算中台内直接查看合同详情，减少系统切换和人工查找成本
  • 为后续结算流程自动关联合同单价、自动核算等能力打下数据基础

2. 功能概述

在结算中台新增「合同管理」菜单，通过对接 OA 系统接口，定时同步所有已归档合同数据。以合同编号作为唯一标识，展示合同详情、客户信息、版权信息等完整字段。支持列表查看、搜索筛选和详情查看能力。

说明原型

3.1 新增「合同管理」菜单

1、概述

  • 在结算中台左侧导航新增一级菜单入口

2、详细内容

1）菜单名称：「合同管理」

2）菜单位置：结算中台左侧导航栏，建议放在现有菜单之后

3）点击进入合同列表页

4）菜单权限：继承结算中台现有权限体系，需有合同管理查看权限的角色方可见

3、特殊说明

  • 该菜单为只读展示，不涉及合同的新增/编辑/删除操作（合同增删改仍在 OA 系统中完成）

3.4 数据同步机制

1、概述

  • 定义从 OA 系统拉取已归档合同数据的同步策略

2、详细内容

1）同步范围：OA 系统中状态为「已归档」的所有合同

2）同步方式：通过 OA 系统提供的 API 接口拉取数据

3）同步频率：

  • 定时同步：每天凌晨执行一次全量/增量同步（具体方案由研发确认 OA 接口能力后确定）
  • 手动同步：列表页提供「同步数据」按钮，点击后触发即时同步

4）同步标识：以合同编号为唯一 key，已存在的合同更新字段值，新合同新增记录

5）同步状态展示：列表页顶部展示「最近同步时间：YYYY-MM-DD HH:mm:ss」

3、特殊说明

  • OA 系统接口能力需研发侧与 OA 团队对接确认（是否支持增量、分页、字段过滤等）
  • 如 OA 接口不支持增量同步，可采用全量拉取 + 本地比对的方式
  • 同步失败时需记录日志，并在页面上提示「同步异常，请稍后重试」
  • 附件文件建议存储文件链接而非文件本体，点击时跳转 OA 系统查看/下载
无原型

3.5 数据导出（可选）

1、概述

  • 支持将合同列表数据导出为 Excel 文件

2、详细内容

1）列表页提供「导出」按钮

2）导出内容为当前筛选条件下的合同列表（含列表页展示的所有字段）

3）导出格式：Excel（.xlsx）

4）文件名格式：合同列表_YYYYMMDD.xlsx

3、特殊说明

  • 导出数据量较大时需异步处理，导出完成后提示下载
  • 该功能优先级较低，可视排期情况决定是否纳入首期
无原型
